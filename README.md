# Xujun Tan Portfolio

Personal portfolio built with React, Vite, and Tailwind CSS.

## Run locally

**Prerequisites:** Node.js 18+

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env.local` and set `VITE_DEEPSEEK_API_KEY` for the About Me chatbot.
3. Start the dev server:
   ```bash
   npm run dev
   ```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Configured for Vercel (`vercel.json`). Set `VITE_DEEPSEEK_API_KEY` in the project environment variables.
